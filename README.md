**AI-Assisted Cultural Heritage Preservation**

A full-stack application designed to support preliminary visual assessment and documentation of cultural heritage structures using computer vision and image processing.

**Domain-Aware AI Document Summarization and Analytics**

### 4. Pixels to Water

**Crop Image Classification, LAI Estimation, and Irrigation Decision Support**

A research project exploring how crop images and environmental data can support crop monitoring and irrigation decision support. It contains two separate research workstreams: sorghum cultivar classification and lettuce Leaf Area Index (LAI) estimation.

- Compares ResNet-18 and EfficientNet-B0 for classifying images into 100 sorghum cultivars.
- Achieves 74.2% test accuracy with EfficientNet-B0 on the project's evaluated sorghum test split.
- Evaluates Random Forest and CNN-based approaches for lettuce LAI estimation.
- The Random Forest model using RGB summary features achieved a test R² of 0.866 on the evaluated LAI split.
- Implements a rule-based irrigation-demand indicator using estimated LAI, reference evapotranspiration (ET₀), growing environment, and rainfall.
- Includes Jupyter notebooks, model evaluation results, experiment documentation, and a Tkinter decision-support prototype.

**Tech Stack:** Python, PyTorch, Torchvision, Scikit-learn, Pandas, NumPy, OpenCV, Jupyter Notebook.
